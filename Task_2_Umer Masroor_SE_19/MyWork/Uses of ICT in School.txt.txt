1. LEARNING - Online Classes
Use: To attend class on Zoom from home.
Advantage: It saves time.
Disadvantage: Class is missed if internet is off.

2. LEARNING - YouTube Tutorials
Use: To learn difficult topics from YouTube.
Advantage: We can watch again and again.
Disadvantage: Wrong information can also be found.

3. COMMUNICATION - WhatsApp Group
Use: To ask teacher about homework.
Advantage: We get quick reply.
Disadvantage: Too many messages cause distraction.

4. COMMUNICATION - Email
Use: To send assignment to teacher.
Advantage: It saves paper.
Disadvantage: Sometimes it goes to spam.

5. MANAGEMENT - Attendance System
Use: To mark attendance on computer.
Advantage: No mistake in attendance.
Disadvantage: Problem if system is down.

6. MANAGEMENT - Result System
Use: To check result online.
Advantage: Result is found quickly.
Disadvantage: Problem if password is forgotten.

7. ENTERTAINMENT - Educational Games
Use: To learn through games.
Advantage: Learning becomes fun.
Disadvantage: Too much playing wastes time.

8. ENTERTAINMENT - School Event Videos
Use: To watch school function videos.
Advantage: Memories are saved.
Disadvantage: Too much screen time is bad for eyes.
